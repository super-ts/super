Lancé le 2026-11-25 à la demande de l'utilisateur : remplacer les templates lit de `render()` par des fichiers `.super` où les éléments sont des instructions (style Ripple), outillés « avec Volar ».

**Why:** typage complet des templates (narrowing, props, événements) ; l'utilisateur a choisi le style Ripple plutôt que `@if/@for` façon Angular parce que le TS virtuel est quasi identique à la source.
**How to apply:** suivre `packages/lang/SPEC.md` (source de vérité de la syntaxe) ; ne pas re-litiger les choix ci-dessous.

Décisions : texte brut autorisé ; espaces = règle HTML (choix utilisateur 2026-11-25, la règle JSX donnait « Cafés2 », « contenantoffline ») ; formes réservées `if (`, `for (`, `switch (`, `const|let <motif> =` ; texte ambigu = erreur + correction « entourer d'accolades » (jamais deviner) ; `for (const x of xs; key x.id)` ; `on:event`, `prop:x`, `ref={this.x}` pour les références (choix utilisateur), directive `{expr}` dans la balise pour form.bind/field ; composant = balise majuscule → `X.create(props, { on })` ; extension `.super` ; l'utilisateur est sur Zed (Tree-sitter, pas TextMate).
